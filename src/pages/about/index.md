# 关于梁相

**众香成势，梁子显相。**

梁相是一个 DeepSeek Harness 社区玩法。每天一道梁案，使用 DSH 凝成香火，花一炷选择夯或拉；社区香火汇成梁位，决定今日梁子。每天结案后，结果收入梁祠。

<h2 id="story">为什么叫“梁相”</h2>

“相”有两层意思：它是梁子在当日梁位下呈现的**形相**，也承接宝相、显相的轻微仪式感。于是香火、梁位、上达天听与梁祠自然进入同一套叙事，但产品并不宣称宗教属性。

这也解释了为什么品牌必须写作 **梁相**，而不是“梁向”。前者说的是显出的形相；后者会把产品误读成方向判断，故事的重心完全不同。

每天的叙事只有一条主线：

```text
今日开梁案
→ 众人用 DSH 凝香表态
→ 众香汇成梁位
→ 梁子依势显相
→ 日终封存梁祠
```

<h2 id="maintainers">作者与维护</h2>

梁相由个人开发者发起，目前通过 **liang-today** GitHub 组织维护官网与社区品牌资产；插件代码与技术文档保留在原始源码仓库。贡献与作者归属以各仓库的提交历史为准。

项目欢迎围绕代码、测试、可访问性、视觉一致性和 DSH 兼容性的改进。为了保护日常使用，所有功能变化都应先通过冻结产品契约与信任边界的审视。

<h2 id="principles">设计原则</h2>

### 现代编年志 × 克制梁祠

视觉以现代桌面产品为底：干净的层级、系统字体、中性色和稳定的信息密度。日历、编年与少量朱印提供识别；暖金和朱红只做标点，不铺成宫殿背景。

### 好玩，但不模糊事实

- 投票永远只有夯与拉。
- 梁位是社区节点的夯率，不是民调或本人立场。
- 五行香客表示独立安装数，不是实名人数。
- 网站只是说明与演示，不处理真实投票。
- 当前身份与 Token 是社区软信任，不能宣传成服务器可验证。

### 热闹留给梁子，秩序留给系统

梁子的上下弹跳可以荒诞，规则、账本和归档必须克制。个人香火环与全局梁位在画面上叠在一起，在数据上绝不混成一个分数。
