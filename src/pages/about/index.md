# 关于梁相

**众香成势，梁子显相。梁相还得梁人出！**

梁相是一个 DeepSeek Harness 社区玩法。每天一道梁案，大家在使用模型的过程中凝成香火，投下一炷“夯”或“拉”；众人的选择汇成梁位，显出今日梁子。日终之后，结果收入梁祠。

<h2 id="story">为什么叫“梁相”</h2>

“相”有两层意思：它是梁子在当日梁位下呈现的**形相**，也承接宝相、显相的轻微仪式感。香火、梁位、上达天听与梁祠因此进入同一套叙事，但产品并不宣称宗教属性。

品牌写作 **梁相**，不是“梁向”。前者说的是被众香显出的形相；后者会把产品误读成方向判断。

```text
今日开梁案
→ 众人用 DeepSeek Harness 凝香表态
→ 众香汇成梁位
→ 梁子依势显相
→ 日终结果收入梁祠
```

<h2 id="open-source">作者与开源</h2>

梁相由个人开发者发起，由 **liang-today** GitHub 组织维护品牌与官网。插件、文档和测试在 [`NiYa193/dsh-liang-meter`](https://github.com/NiYa193/dsh-liang-meter) 开源；官网在 [`liang-today/liang-today.github.io`](https://github.com/liang-today/liang-today.github.io) 开源。作者与贡献者信息以仓库提交记录为准。

当前版本为 **0.6.0 RC**。正式 Release 发布后，安装包与更新说明会出现在插件仓库的 Releases 页面。

<h2 id="principles">设计原则</h2>

### 现代编年志 × 克制梁祠

界面以现代桌面产品为底：清晰层级、稳定信息密度与克制的中性色。日历、编年与少量朱印提供识别；暖金和朱红只做标点，不铺成宫殿背景。

### 好玩，但不模糊事实

- 投票只有夯与拉，一炷就是一票。
- 梁位是社区参与者的夯率，不是民调或本人立场。
- 五行香客表示至少成功投过一次的参与者数量，不等于实名人数。
- 官网只提供说明与演示，不处理真实投票。

### 热闹留给梁子，秩序留给系统

梁子的上下弹跳可以荒诞，投票与归档保持清楚。个人香火与全局梁位在画面上相遇，在计算中始终分开。
